# Assets and licenses

No third-party assets, asset packs or plugins are used in this project.

| Asset | Location | Source | License |
| --- | --- | --- | --- |
| Sound effects and ambience loops (42 WAV) | `assets/sounds/` | Synthesised by `tools/gen_audio.py` | CC0 1.0 |
| Music loops (4 WAV) | `assets/music/` | Synthesised by `tools/gen_audio.py` | CC0 1.0 |
| Tileable textures (18 PNG, 64x64) | `assets/textures/` | Generated by `tools/gen_textures.py` | CC0 1.0 |
| Item icons (30 PNG, 32x32) and app icon | `assets/ui/` | Generated by `tools/gen_icons.py` | CC0 1.0 |
| 3D models (train, locations, characters, enemies, items) | built at run time in `scripts/` | Assembled in code from Godot primitive meshes | part of the project code |
| Post-process shader | `shaders/ps1_post.gdshader` | Written for this project | part of the project code |
| Interface font | not in the repository | Godot's built-in default font (Open Sans) | SIL Open Font License 1.1 |

The generators are deterministic: `python3 tools/gen_audio.py`, `tools/gen_textures.py` and
`tools/gen_icons.py` (they need `numpy`) recreate the files, and `tools/verify_assets.py`
checks formats, durations and loop seams.
